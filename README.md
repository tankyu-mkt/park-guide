# 公園の正しい使い方

公園のルールを紹介する、かんたんなWebサイトです。右上の「Language」で10ヶ国語（日本語、英語、中国語（簡体字・繁体字）、韓国語、ドイツ語、フランス語、イタリア語、スペイン語、ポルトガル語）を切り替えられます。基本はGitHubだけで動きます（外部サービスを使うのは、フィードバックの送信のみ）。

- `index.html`：ホームページ
- `rules.html`：ルールのページ
- `game.html`：ゲーム一覧のページ
- `runner.html` / `runner.js`：パークランナー（走るゲーム）
- `litter.html` / `litter.js`：ごみひろいゲーム（この端末のランキング）
- `feedback.html` / `feedback.js`：フィードバック（メールで管理者に届く。送信には外部サービスのFormSubmitを使用）
- `lang.js`：言語の切り替えと、各言語の文章
- `style.css`：ヘッダー、フッターなどの見た目
